## 잘 된 것

- **루프 규율 충실 이행**: 매 단계 표기, Context 참고 자산 줄, 결정은 AskUserQuestion으로 사용자에게,
  적대 검토를 승인 전에, 회고 후 커밋. 사용자 요청(복리 위한 6원칙)을 지켰다.
- **적대 검토가 joins의 §6 우회 구멍 4건(C1~C4)을 사전 차단** — 특히 joinEqualities 수집을 §6.1 경계에
  얹는 설계로 OUTER·OR 우회를 "위치"만으로 막았다. 코드 전 스펙에서 고친 게 재작업을 없앴다.
- **판정 핵심(IR·평가기)은 직접 작성, 화면만 위임** — 고위험 로직을 직접 쥐고 컨텍스트를 아꼈다.
- **시드 스크립트(docker/seed.sh) 자산화** — 회고 003/004에서 남긴 "수동 curl 시드" 숙제를 해결. 재현 가능.
